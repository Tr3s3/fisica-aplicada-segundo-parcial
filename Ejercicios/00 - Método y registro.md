# Método de práctica y registro de errores

Este archivo contiene una rutina para resolver y un registro para elegir qué rehacer. Las hojas por tema están enlazadas abajo.

Esta nota está organizada para que puedas **entender qué representa cada dato, elegir el modelo y practicar sin ver la respuesta antes de tiempo**. Los ejercicios **M** reproducen tipos que aparecen en los modelos de parcial; los **R** son variantes nuevas para comprobar que sabes transferir el método.

## Rutina para resolver cada problema

1. Lee la situación y marca qué objeto o sistema estudias.
2. Anota los datos con unidades SI y define la incógnita.
3. Haz un esquema o identifica el marco de referencia cuando corresponda.
4. Escribe la ley física antes de reemplazar números y explica por qué aplica.
5. Despeja, calcula con unidades y revisa si el resultado tiene sentido.
6. Abre la pista solo si te trabas. Deja la clave para el final.
