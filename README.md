# Física Aplicada — segundo parcial

Vault de estudio para preparar el segundo parcial de Física Aplicada. El material está organizado por tema y combina teoría, ejercicios de práctica, resoluciones guiadas y un plan intensivo de tres días.

## Cómo empezar

1. Abre esta carpeta como vault en Obsidian.
2. Empieza por [Inicio.md](Inicio.md).
3. Sigue el [Plan de 7 días](Plan%20de%207%20d%C3%ADas.md).
4. En cada tema, estudia teoría, practica sin abrir las pistas y consulta las resoluciones después.

## Estructura

- Teoría/: formulario general y teoría por tema.
- Ejercicios/: práctica por tema, pistas plegables y claves.
- Resoluciones/: ejemplos resueltos paso a paso por tema.
- imagenes/: diagramas SVG usados en las notas.
- Fuentes Zotero y probabilidad.md: modelos y materiales de referencia.

## Formato

El vault usa Markdown, fórmulas LaTeX/MathJax, enlaces internos de Obsidian, callouts plegables y diagramas SVG. No requiere plugins comunitarios. La carpeta .obsidian/, que contiene preferencias locales, el estado de ventanas y la lista de plugins instalados, no se incluye en el repositorio.
